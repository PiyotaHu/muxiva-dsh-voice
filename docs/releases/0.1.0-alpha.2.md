# Muxiva Voice 0.1.0-alpha.2

This alpha makes the public npm path the primary installation experience and certifies the current voice pipeline against DeepSeek Harness `0.1.0-rc.6`.

## Highlights

- More reliable Chinese/English ASR: a two-second conversational endpoint, stronger VAD and minimum-speech gates, language admission, and punctuation/noise hallucination rejection.
- ASR-confirmed interruption: VAD alone never cancels the Agent or TTS; meaningful recognized text confirms barge-in.
- Persistent microphone mute: the browser Source pauses without tearing down Web Audio, WebSocket, Muxiva Graph, or the local models.
- More consistent local Qwen3-TTS: Serena, a calm Mandarin delivery profile, conservative sampling, bounded PCM pacing, and a two-stage context policy that avoids sentence-by-sentence prosody resets.
- Cleaner spoken output: Markdown, emoji, URLs, email addresses, horizontal rules, decorative dashes, and residual display syntax are removed before TTS.
- Stable local data: npm/npx installations keep models, the Python environment, logs, and versioned runtime assets outside the npm cache.
- Correct DSH compatibility metadata: Cordis `^4.0.1`; DSH client rc.5 and rc.6 are explicitly supported.

## Install

```bash
dsh plugin --profile web add @muxiva/dsh-voice@alpha
npx @muxiva/dsh-voice@alpha setup
npx @muxiva/dsh-voice@alpha start
```

Start `dsh --profile web` in a second terminal. Use `npx @muxiva/dsh-voice@alpha start --observe` to open Muxiva Studio with live Node, Edge, queue, buffer, and trace telemetry.

## Compatibility

- macOS on Apple Silicon
- Node.js 22.19 or newer
- Python 3.11–3.13
- Muxiva 0.1.1
- DeepSeek Harness 0.1.0-rc.5 or 0.1.0-rc.6; certification target: rc.6

The attached M1 Pro JSON is the complete unattended release certification report. Model weights are downloaded separately and remain under their upstream licenses.

The report uses the explicitly versioned `reliability-alpha-v1` policy. Its p95 results are 14.9 ms capture admission, 1157.0 ms ASR-confirmed barge-in, 2181.2 ms speech-end-to-Final (including the configured two-second silence hold), 1175.3 ms complete-context TTS first PCM, 227.2 ms queue-ahead, and zero stale audio after interruption. All 130 turns passed with zero underruns.
